Descripción del proyecto:
Programa desarrollado en el lenguaje de programación Java y JavaFX siguiendo el modelo MVC (modelo, vista, controlador).

Requisitos del sistema:
Este programa fue iniciado y probado con los siguientes requisitos:
Java JDK versión 25.
JavaFX configurado en el entorno de desarrollo.

Instrucciones de ejecución:
1.Estar ubicado dentro de la carpeta "src" en el entorno de desarrollo. 
2.Dirigirse a la carpeta "vista".
3.Buscar, entrar y ejecutar el programa en "Launcher.java".
